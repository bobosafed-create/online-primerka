# Задача №2 — аналитика и Яндекс Метрика

Дата подготовки: 21 июля 2026 года.

## Назначение

Сайт подключён к счётчику `110910242`. Переменная окружения `YANDEX_METRIKA_ID` в Timeweb позволяет при необходимости переопределить номер без изменения кода.

Включены:

- просмотры страниц;
- карта кликов;
- отслеживание внешних ссылок;
- точный показатель отказов;
- Вебвизор.

Загруженные посетителями фотографии и готовые результаты отмечены классом `ym-hide-content`, поэтому их содержимое должно быть скрыто в записях Вебвизора.

## События воронки

| Идентификатор цели | Когда отправляется | Параметры |
|---|---|---|
| `start_tryon` | Нажатие кнопки на первом экране | `placement` |
| `demo_video_open` | Открытие демонстрационного видео | — |
| `garment_uploaded` | Загрузка первой фотографии вещи | `source`, `item_count` |
| `garments_ready` | Загружено минимум две вещи | `item_count` |
| `payment_start` | Нажатие реальной кнопки оплаты | `item_count`, `order_price`, `currency` |
| `purchase` | Сервер подтвердил успешную реальную оплату | `order_price`, `currency` |
| `model_selected` | Выбрана модель | `model_id` |
| `generation_start` | Сервер принял задачу генерации | `kind`, `model_id` |
| `generation_success` | Получен готовый результат | `kind`, `model_id` |
| `result_download` | Нажато скачивание результата | `kind` |

`kind` принимает значение `photo` или `video`. Тестовые заказы не отправляют цель `purchase`.

## Созданные цели в Метрике

Все 10 целей созданы 21 июля 2026 года в счётчике `110910242`. Тип каждой цели — **Целевое событие (JavaScript-событие)**, условие — точное совпадение идентификатора.

Основные цели для рекламы:

1. `purchase` — главная цель, подтверждённая покупка с доходом.
2. `garments_ready` — промежуточная цель для первого этапа, пока покупок мало.
3. `payment_start` — диагностика потерь перед ЮKassa.

Дополнительные цели для анализа продукта:

- `start_tryon`;
- `garment_uploaded`;
- `model_selected`;
- `generation_start`;
- `generation_success`;
- `result_download`;
- `demo_video_open`.

## Воронка отчёта

`start_tryon` → `garment_uploaded` → `garments_ready` → `payment_start` → `purchase` → `model_selected` → `generation_start` → `generation_success` → `result_download`

## Проверка после публикации

Проверено 21 июля 2026 года на опубликованном сайте с параметром `_ym_debug=1`:

- просмотр страницы передаётся в счётчик `110910242`;
- `start_tryon` передаётся;
- `demo_video_open` передаётся;
- `garment_uploaded` передаётся;
- `garments_ready` передаётся после загрузки двух демонстрационных вещей;
- кнопка оплаты после двух загрузок активируется;
- реальные оплата и генерация во время проверки не запускались.

После включения оплаты нужно выполнить отдельный контрольный платёж и проверить `payment_start` и `purchase` с суммой и валютой `RUB`. После этого отдельно проверить `model_selected`, `generation_start`, `generation_success` и `result_download`.
