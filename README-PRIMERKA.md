# Онлайн примерка — отдельное приложение (freemium)

Мобильное приложение. Модель «попробуй бесплатно, заплати за чистый результат»:

1. **Загрузка одежды** — «Сделать ФОТО» / «Загрузить из галереи». Нужны минимум одна вещь верх и одна низ; всего до 6, плюс по желанию доп. вещи. Коррекции цвета/вида нет.
2. **Выбор модели** — один из ИИ-манекенов (мужской/женский).
3. **Бесплатное фото** — генерируется фото образа **с водяным знаком** (1 бесплатное превью на посетителя). Под превью — кнопка «Скачать в HD без водяного знака — 99 ₽».
4. **После оплаты** — открывается **чистое фото в HD** для скачивания **и** кнопка «Создать видео-образ» (видео входит в ту же оплату).

Водяной знак наносится на нашем сервере (Pillow), чистый файл выдаётся только после подтверждённой оплаты. Лимит бесплатных превью — по visitorId (localStorage). Для повторного теста бесплатного превью очистите данные сайта в браузере (сменится visitorId) или передеплойте приложение (сбрасывает счётчик в /tmp).

> Требуется пакет **Pillow** (добавлен в requirements.txt) — Timeweb поставит его при деплое.

Примерку делает сервис **WaveSpeedAI**. На шаге 4 клиент выбирает формат:

- **📷 Фото** — быстрая картинка (~15–30 сек), модель `wavespeed-ai/ai-clothes-changer`, **≈ $0.12** за результат.
- **🎬 Видео** — одежда на движущейся модели (~1–2 мин), модель `wavespeed-ai/ai-virtual-outfit-tryon`, **≈ $0.20** за ролик.

Оба варианта берут одно фото манекена + фото одежды. При цене 99 ₽ (~$1.1) маржа хорошая в обоих случаях. Видео дольше по своей природе — быстрее его сделать нельзя, поэтому и добавлена быстрая кнопка «Фото» для тех, кто не хочет ждать.

## Файлы

- `main.py` — бэкенд (FastAPI): загрузка, оплата, видео-примерка, админка.
- `index.html` — интерфейс (4 шага, под телефон).
- `admin.html` — админ-панель (выручка, заказы, цена, тестовый режим). Адрес: `/admin`.
- `oferta.html`, `politika.html`, `kontakty.html` — юридические страницы.
- `requirements.txt` — зависимости.

## Что нужно приложить рядом с `main.py`

**Кадры манекенов (обязательно):** `model-1.jpg`, `model-2.jpg`, `model-3.jpg` — по одному **чёткому фото** каждого манекена в полный рост (это «модель», на которую надевается одежда). Из ваших видео нужно взять по одному стоп-кадру. Если пришлёте мне три видео — я вырежу удачные кадры сам.

**Видео манекенов (по желанию):** `mannequin-1.mp4`, `mannequin-2.mp4`, `mannequin-3.mp4` — если положите, на шаге выбора будут крутиться ваши ролики (красивее). Не положите — покажутся фото-кадры.

## Развёртывание (отдельный проект в Timeweb)

Это **отдельная программа**, поэтому заводится своим проектом — не смешивается с «Гардеробом мира».

1. Создайте **новый репозиторий** на GitHub, залейте туда все файлы из этой папки (в корень).
2. В Timeweb App Platform создайте **новое приложение** из этого репозитория (Python).
3. Команда запуска: `uvicorn main:app --host 0.0.0.0 --port 8000` (порт **8000**, как в прошлый раз).
4. Healthcheck-путь: `/api/health`.
5. Задайте переменные окружения (см. ниже) и дождитесь деплоя.

### Переменные окружения

| Переменная | Значение |
|---|---|
| `YOOKASSA_SHOP_ID` | ваш ShopID ЮKassa |
| `YOOKASSA_SECRET_KEY` | секретный ключ ЮKassa |
| `SITE_URL` | адрес нового приложения (например `https://ваш-новый-адрес.twc1.net`) — **важно**, по нему WaveSpeed скачивает фото |
| `SERVICE_PRICE` | `99.00` |
| `ADMIN_PASSWORD` | пароль для входа в `/admin` |
| `WAVESPEED_API_KEY` | ваш ключ WaveSpeedAI |
| `WAVESPEED_MODEL` | (необязательно) видео-модель, по умолчанию `wavespeed-ai/ai-virtual-outfit-tryon` |
| `WAVESPEED_PHOTO_MODEL` | (необязательно) быстрая фото-модель, по умолчанию `wavespeed-ai/ai-clothes-changer` |
| `TRYON_DURATION` | (необязательно) длительность видео в секундах, по умолчанию `5` |

Примерка включается автоматически, когда задан `WAVESPEED_API_KEY` **и** есть хотя бы один файл `model-*.jpg`.

> **Важно про `SITE_URL`:** сервис WaveSpeed скачивает фото манекена и одежды по публичным ссылкам вашего сайта. Если `SITE_URL` указан неверно — видео не сформируется. Впишите точный адрес нового приложения.

## Тестовый режим (без реальной оплаты)

В `/admin` включите «Тестовый режим» — тогда шаг оплаты пропускается и можно проверить примерку. **Внимание:** даже в тестовом режиме генерация видео тратит кредиты WaveSpeed (это реальный вызов сервиса).

## Честно о рисках

Живой вызов WaveSpeedAI я в этой среде проверить не мог (нужен ваш ключ и сеть). Контракт взят из их документации: `POST /api/v3/wavespeed-ai/ai-virtual-outfit-tryon`, тело `{image, clothes_images[], duration}`, затем опрос результата. Разбор ответа я сделал устойчивым к разным форматам. На реальном ключе, возможно, потребуется 1–2 мелкие правки (например, точный адрес опроса или поле с URL видео). Если что-то не заработает — пришлите текст ошибки из логов Timeweb, поправлю быстро.

Ещё поправьте в `oferta.html` адрес сайта (строка с `https://bobosafed-create-stylemylife...`) на адрес нового приложения.
