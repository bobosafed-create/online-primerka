# StyleGlobe для селлеров — инструкция по запуску

Сервис каталожных фото для маркетплейсов (Wildberries, Ozon). Клиент загружает фото одежды,
получает первое превью бесплатно (с водяным знаком), покупает пакет генераций и по коду доступа
скачивает фото/видео в HD без водяного знака.

## ВАЖНО: куда деплоить

Этот сервис заменяет предыдущее приложение «Онлайн примерка» на ТОМ ЖЕ адресе:
**https://bobosafed-create-online-primerka-e314.twc1.net**

Адрес сохраняется специально — под него уже настроена реклама в Яндекс Директ, и на нём подтверждены
права в Яндекс Вебмастере (мета-тег `yandex-verification` уже вшит в главную страницу).
Поэтому загружайте эти файлы в тот же репозиторий / то же приложение Timeweb, что и раньше.

Старая версия («Онлайн примерка» за 99 ₽) сохранена в архиве `primerka-BACKUP-rozica-99r.zip` —
если понадобится откат, можно вернуть её файлы.

## Настройки приложения (переменные окружения в Timeweb)

Задавайте секреты ТОЛЬКО в панели Timeweb (Переменные окружения), НЕ в коде и НЕ в переписке.

| Переменная            | Назначение                                              | Обязательна |
|-----------------------|---------------------------------------------------------|-------------|
| `DATABASE_URL`        | Строка подключения PostgreSQL — **обязательно!**        | ДА          |
| `ADMIN_PASSWORD`      | Пароль в админку `/admin`                               | ДА          |
| `SITE_URL`            | https://bobosafed-create-online-primerka-e314.twc1.net  | ДА          |
| `WAVESPEED_API_KEY`   | Ключ WaveSpeedAI (генерация фото/видео)                 | ДА          |
| `YOOKASSA_SHOP_ID`    | ID магазина ЮKassa                                      | для оплаты  |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa                                   | для оплаты  |

### Про `DATABASE_URL` — почему это критично

Балансы кодов доступа (сколько генераций осталось) хранятся в базе. Без `DATABASE_URL` сервер
использует **временную** базу, которая обнуляется при каждом перезапуске/передеплое — то есть
оплаченные клиентом генерации пропадут. Поэтому для продаж PostgreSQL **обязателен**.

Как подключить на Timeweb:
1. В панели Timeweb создайте базу данных PostgreSQL.
2. Скопируйте строку подключения (обычно вида `postgresql://user:pass@host:port/dbname`).
3. Вставьте её в переменную `DATABASE_URL` в настройках приложения. Сохраните и передеплойте.
4. Зайдите в `/admin` — вверху не должно быть предупреждения о временной базе.

## Запуск

- Команда запуска: `uvicorn main:app --host 0.0.0.0 --port 8000`
- Проверка здоровья (healthcheck): `/api/health`
- Python 3.13

## Как тестировать перед боем

1. В `/admin` включите «Тестовый режим» — оплата будет проходить без реальных денег.
2. Пройдите путь: загрузите фото → бесплатное превью → «купить пакет» → получите код → сгенерируйте фото.
3. Проверьте, что баланс кода уменьшается и что после исчерпания генераций сервис просит купить ещё.
4. Убедитесь, что предупреждения о временной базе в админке НЕТ (значит `DATABASE_URL` подключён).
5. Выключите тестовый режим — сервис готов к боевой оплате.
