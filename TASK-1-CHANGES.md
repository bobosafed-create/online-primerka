# Задача №1 — первый экран «до/после»

Дата подготовки: 21 июля 2026 года.

## Что изменено

- Добавлен новый мобильный первый экран с понятным обещанием результата.
- Добавлена демонстрация «верх + низ → готовый образ».
- Добавлена кнопка «Начать примерку за 99 ₽», ведущая к загрузке одежды.
- Цена в первом экране синхронизируется с `/api/config`.
- Добавлен раскрывающийся пример короткого видео.
- Добавлены короткие элементы доверия: работа в браузере, без установки, оплата через ЮKassa.
- Добавлено пояснение, что результат создаётся на выбранной модели и фотография пользователя не требуется.
- Серверу добавлена раздача файлов из каталога `assets`.

## Что не изменялось

- ЮKassa и логика оплаты.
- Интеграция WaveSpeedAI.
- Загрузка пользовательских фотографий.
- Админ-панель.
- Юридические страницы.
- Настройки и секреты Timeweb.

## Новые файлы

- `assets/before-top.jpg`
- `assets/before-bottom.jpg`
- `assets/after-result.jpg`
- `assets/result-video.mp4`

## Перед публикацией

1. Сохранить текущую рабочую версию сайта и настройки окружения Timeweb.
2. Загрузить эту версию в отдельную ветку GitHub или сделать отдельный коммит.
3. Проверить тестовый заказ на телефоне без реальной оплаты.
4. После проверки включить оплату и выполнить один контрольный платёж на 99 ₽.
